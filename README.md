# Starforge Liquid Test

This project now includes an ONI-like pressure model for liquid flow.

## Quick Test
1. Fill a central column of tiles with liquid amounts close to `MAX_CAP`.
2. Add a spring along one side wall to push the liquid for several ticks.
3. Observe the neighbouring tiles briefly overfill then rapidly equalize as pressure dissipates.

This scenario demonstrates transient overcompression and fast horizontal balancing.
